# Lab 4 Report — CSS Layout + Responsive E-Commerce Frontend

**Student:** Amyy  
**Course:** Web Technologies  
**Lab:** 4

## 1. Objective
To build a responsive e-commerce frontend and practice CSS Grid, Flexbox, responsive images/layouts and media queries.

## 2. Implementation
The project contains Home, Products, Product Details, Cart, Checkout, Login and Register pages. CSS Grid is used for product/category layouts, Flexbox for navigation and aligned content, and media queries adapt the layout for smaller screens. JavaScript provides demo product filtering and cart interactions.

## 3. Result
A multi-page responsive e-commerce frontend was created. The layout can be tested at desktop, tablet and mobile widths.

## 4. Problems and Solutions
- If CSS does not load, check that every HTML page links to `css/style.css` and that the `css` folder is beside the HTML files.
- If navigation does not work, verify exact page filenames.
- If the layout overflows, inspect wide elements and media query breakpoints.
