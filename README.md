# Amyy Store — Lab 4 E-Commerce Frontend

## About
A responsive, multi-page e-commerce frontend created for Web Technologies Lab 4. It demonstrates CSS Grid, Flexbox, media queries, responsive layouts, product cards, a demo cart, and HTML form validation.

## Pages
- `index.html` — Home page
- `products.html` — Product listing with search and category filter
- `product.html` — Product details
- `cart.html` — Demo shopping cart
- `checkout.html` — Responsive checkout form
- `login.html` — Login form UI
- `register.html` — Registration form UI

## Run
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser, or use VS Code Live Server.
4. Navigate through all pages using the navbar.

## Important
This is a frontend classroom demo. It does not include PHP, MySQL, real user authentication, payment processing, or order storage on a server. The cart uses browser `localStorage`.

## Lab concepts
- CSS Grid: product listing and category layout.
- Flexbox: navigation, product information and summary rows.
- Media queries: tablet and mobile breakpoints.
- Responsive design: layouts adapt to screen width.
- Form validation: required fields, email type, minlength and pattern.
